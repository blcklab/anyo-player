# Maintainer notes

This directory is repository-only material for people maintaining and releasing `@blcklab/anyo-player`.

It is intentionally excluded from the npm package. Public package documentation belongs in `README.md` and `docs/`.

## What belongs here

- release procedures and provenance checks;
- validation evidence and physical-device procedures;
- internal architecture ownership notes;
- historical milestone/release-candidate material;
- clean-source handoff notes.

Do not link package users here from published documentation. If a topic affects how an application should use Player, document that behavior publicly under `docs/` instead.
